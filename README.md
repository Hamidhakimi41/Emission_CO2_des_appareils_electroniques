## Sujet

Notre sujet traite de l'impact écologique du numérique : analyse de l'impact écologique de différents appareils électroniques à travers différentes mesures. Ces visualisations comprennent un bubble chart couplé à un scatter plot, ainsi que des courbes. En plus de cela, nous avons une carte de flux. Vous pourrez trouver plus de précisions dans le wiki du projet.

## Instructions pour lancer le projet
Deux manières de lancer : 
- soit cliquer sur l'adresse suivante : http://data-visualisation-grp10-cef50c.pages.univ-lyon1.fr/
- soit ouvrir le projet sur VSCode et utiliser l'extension live server pour ouvrir la page index.html à la racine du projet
